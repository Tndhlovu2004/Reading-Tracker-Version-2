# READING TRACKER

## Overview

The Reading Tracker is a program that I designed to help users track the books they have read over the course of a given year. This project is a rebuild of a program I had previously created as a way to foster more independent learning. Having recently declared Computer Science as my major, I wanted to use this project to improve my programming skills whilst creating something that was tied to my personal interests. As an avid reader and English minor, I wanted to create a tool that I could see myself using as well as something other readers might also find useful. I hope to continue creating projects like this for myself and others in the future.

## Features

- Allows a user to enter details of specific books.
- Uses dictionaries to store specific book information.
- Uses functions to add and view book information.
- Uses JSON to save and load books, name and year information.
- Uses a number of while loops to help with program flow.
- Utilises input validation. 
- Uses conditional if statements to help create a functioning user menu. 

## Requirements

- Python has to be installed on your computer.
- A code editor like Visual Studio Code is recommended to run the program.

## How to Run

- Download the reading_tracker.py file from my GitHub repository onto your computer.
- The file needs to be opened using a code editor such as Visual Studio Code.
- Once open, you need to click the triangular run button in the upper right corner of the editor to run the program.

## How to use

- A prompt from the program will appear after you click the run button.
- You simply need to follow this and other subsequent prompts of the program in order to use it. There will also be a prompt that allows you to exit. 
- Your book, year and name information will be saved to three json files bas you use the program ("books.json," "name.json," and "year.json."). Once you exit the program, your data will be restored once you return.
